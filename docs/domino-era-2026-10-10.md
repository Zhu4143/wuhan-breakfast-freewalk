# 今昔接力动画 · 2026-10-10

六家店按街口到巷尾逐家起步。今日→昔日反向播放，从巷尾退回街口。相邻店铺之间有少量交叠：下一家墙面翻起时，上一家正在收尾，形成连续的多米诺节奏。

## 节奏

完整动画标称 6.36 秒；每家相隔 0.88 秒开始，单店 1.96 秒。

| 店铺 | 正向起步 |
| --- | --- |
| 林记热干面 | 0.00 秒 |
| 豆皮铺 | 0.88 秒 |
| 面窝摊 | 1.76 秒 |
| 何记糊汤粉 | 2.64 秒 |
| 桂姨烧梅铺 | 3.52 秒 |
| 巷尾汤包馆 | 4.40 秒 |

每家店内部：四片墙依次翻转（每片间隔 0.12 秒）→招牌、柜面与器物→独立店主人物→食物轻倾与蒸汽收尾。面窝画中的人物保留在原绘制墙面中，随墙片变化；该店另外分开柜面与食物。共享的食物与老物件保留身份，通过动作接力。

门面修缮、路灯、开门帘、街边生活物件和行人按附近店铺的进度变化。石板路按六段沿街递进，接缝做柔和过渡；全局晨光用各铺平均进度过渡，不改变清晨时间。

## 代码

- `src/street/eraDomino.ts`：起步顺序、时间参数、分层采样与附近店铺归属；位置读取现有 `layout.ts`。
- `src/atelier/EraSequence.ts`、`SceneExtension.ts`：可选的分层动画契约。
- `AtelierScene.ts`：GSAP 接力播放头、热干面分层；原独立场景仍保留其原翻转路径。
- `MorningStreet.ts`：把每铺进度分发到店铺、街景、地面与当地声音。
- `DoupiShop.ts`、`BreakfastKitchen.ts`、`FoodStalls.ts`：墙片、器物、人物与食物分离，分别批处理以保留动画根节点。
- `StreetEras.ts`、`StreetLifeDetails.ts`、`MarketAtmosphere.ts`、`AgedPaving.ts`：沿街细节和地面跟随当地变化。
- `tests/era-domino.test.ts`：顺序、分层、反向、端点与空间归属。

“静一静”暂停环境动画，但主动今昔切换仍完整执行。2026-10-10 后续修正：切换期间允许第一人称移动、转向、自动行走及“继续走走”；年代按钮和店铺选择仍等待最后一铺结束，弹窗仍阻止本地移动。详见 `era-walk-slider-2026-10-10.md`。首次加载从存档端点直接建立场景；GSAP 播放头在再次切换或释放场景时被清理。
