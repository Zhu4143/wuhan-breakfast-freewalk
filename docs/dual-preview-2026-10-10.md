# 手机与电脑同步对照预览

入口：`http://127.0.0.1:5193/?preview=dual`。普通入口 `/` 仍为原体验；部署在项目子目录时，保留原路径并加 `?preview=dual`。

## 使用

- 左侧为电脑页面，右侧为带黑色机身、顶部岛形区域的手机页面。
- 电脑可选 1024、1280、1440 × 800；手机可选 375 × 812、390 × 844、430 × 932。
- 两个 iframe 各有独立的 CSS 视口，外层缩放只影响展示大小，不会把电脑样式挤成手机样式。
- 在任意一端操作即可接管同步：进入街景、行走位置和朝向、视野缩放、今昔、时间与暂停、店铺、章节与故事页、文化问答、食篮及其海报、目录、手册、影笺与制作面板。
- 关闭“双端同步”可独立操作；重新开启时以最后操作端的状态为准。
- 两端可以分别滚动阅读，以查看不同排版。声音由实际操作的一端播放，避免重复配音。
- 预览从正式食篮读取初始进度，但预览修改不写回正式存档；刷新对照页会重新开始本次预览。
- 手机框是浏览器尺寸模拟，不能验证真实手机的摄影权限、系统文件选择器、安全区、触摸手感或设备性能。

## 实现

`src/preview/DualPreview.tsx` 和 `dualPreview.css` 提供对照容器。`previewProtocol.ts` 负责会话、角色、状态键与更新顺序；`previewBridge.ts` 将预览模式接入 React 状态，普通模式仍使用组件本地状态。

父页面使用同源 `postMessage`，同时检查 origin、iframe 的 contentWindow 和随机会话 ID。只有最近输入端推进时间与导航；另一端接收相同的相机位置、朝向和待走路线，继续使用自己的屏幕宽高与手机视野。接收消息不反向发送；每次只转发变更字段，照片和 PNG 不随 100ms 的相机更新重复传输。

接入点：`main.tsx`、`ExploreExperience.tsx`、`useMorningClock.ts`、`FreeWalk.ts`、`MorningStreet.ts`、`CultureConversation.tsx`、`PhotoGallery.tsx`、`PhotoZineStudio.tsx`。仅在明确的子预览会话中启用同步。照片/生成结果在预览时转为本地 data URL，让两个同源 iframe 都能读取；未增加后端或外部模型调用。
