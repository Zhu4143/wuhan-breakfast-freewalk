# 2026-10-11 公开更新

本次在现有 v13 自由行走版本上更新，不改写原项目。公开源码使用 `Zhu4143/wuhan-breakfast-freewalk` 的 `main`，构建网页使用同一仓库的 `gh-pages`，访问无需登录。

- 暖金磨砂玻璃界面及全街晨光；桌面右侧故事卡和手机底部故事卡。
- 六张武汉摄影影笺与六味早餐对应；收藏与移出食篮会同步改变展示的影笺。
- 街坊影笺支持本地照片上传、食物名称、海报合成和下载，手机提供拍照入口。没有后端或 AI 生图调用。
- 今昔变化沿街逐店展开，店内器物分层依次变化；主视角可以同时行走，按钮使用滑块动画。
- 电脑与手机同步预览，任一端可以接管，支持手机尺寸与横竖屏切换。
- 手机对话、目录、食篮等界面的遮挡、标题底色及滚动区域调整；横屏手机框的摄像头与安全区调整。
- 双端预览的独立停帧恢复，在浏览器降低 iframe 动画调度频率时继续推进画面，恢复正常后退出备用调度。普通网页不启用备用调度。

保留第一人称行走、六家早餐店、晨间时间推进、文化交流、93 段人物配音、环境声和收藏。已经取消的 DLSS 小样不作为本次网页入口发布。

## 验证与边界

104 项自动测试通过，生产构建通过。浏览器验证覆盖双端接管、横竖屏切换、菜单、今昔变化与收藏同步。停帧诊断中，受限预览从约每秒 1 次画面更新恢复到约每秒 23 次；“只有手机停住”的现场条件尚未完整复现，不能据此保证所有设备均已解决。

测试命令：`node --experimental-strip-types --test --test-isolation=none tests/*.test.ts`；构建命令：`npm run build`。

实体手机帧率、多指手势和摄像头表现仍需实机验证。080 / 089 配音读音保留人工复核标记。较大的 Three.js 构建分块警告仍存在，进入街景需要下载素材。

发布网站的 `version.json` 保存源码提交与发布时间，可用于判断缓存是否已更新。
