# 街坊影笺 · 武汉照片再创作

此文保留第一轮无食物名称海报的来源和验收记录。同日后续已完成六味过早版本，当前项目使用 `food-zines-v2`，食篮联动及最新说明见 [六味过早影笺与食篮](food-zines-2026-10-09.md)。

将用户提供的六张武汉景观照片逐张按 `scenes-gathered-zine-v1-3` 制作为 3:5 纸质拼贴海报。这批作品由 Codex 的内置图像工具生成，未调用用户的火山账号。

作品在老街原有栏板处（`-5.85, -25.5`）按三列两行展示，两个叙事年代均可浏览。它们是当代照片的艺术再创作，不作为昔日街景的历史证据。栏板前的“街坊影笺”标记、顶部入口和沿街目录都能打开作品集。作品集支持逐张放大、前后切换、方向键、Escape 关闭及前往实体栏板。

## 资产与后续追加

作品名单及文案：`src/street/photoZines.ts`。缩略图与大图：`public/assets/photo-zines-v1/`。本批六张大图约为 960×1600 WebP（第一张高 1599），共 1,472,844 字节；六张 240×400 缩略图共 73,046 字节。场景只加载缩略图，大图仅在点开作品时挂载。贴图解码不阻塞开街；场景销毁后晚到的图片解码不会再创建资源。

## 本地查看

项目目录运行 `npm.cmd run build`，再运行 `npm.cmd run preview -- --port 5193 --strictPort`。打开 `http://127.0.0.1:5193/`，进入老街后点击“街坊影笺”。本次未更新线上 GitHub Pages。

已通过构建与 83 项现有测试。在真实浏览器检查了实体栏板、六张大图、切换、关闭后恢复操作，以及 390×844 手机排版。截图和检查记录在 `../culture-qa/photo-zines-20261009/verification.md`。
