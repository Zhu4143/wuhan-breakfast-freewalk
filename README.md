# 过早旧影 · 武汉老街

在淡彩绘本老街里，以第一人称走近武汉早餐铺，看看整条街的昔日与今日。停留约五分钟，从 05:00 的薄明走到 08:00 的早市。

## 操作

- 电脑：WASD / 方向键移动，拖动画面转向，滚轮缩放。
- 手机：左下摇杆移动，拖动街景转向，右下加减按钮缩放。
- 点每家店铺前的交互按钮可沿街走近；“继续走走”从当前位置自由行动。
- 自动路线会避让行人和街道障碍，到店处被占用时停在附近安全位置；WASD 或摇杆可接管。
- 下方时间条可暂停或拖动预览。留在街上约五分钟，天空逐渐亮起，街灯淡下，四位早起的人逐步增加到十八位，六处铺门依次打开。离开页面或回到封面不推进时间。
- “昔日 / 今日”沿街逐店改变建筑与早餐铺，店内器物也依次变化；切换期间仍可自由行走。
- 点击“声音关”开启声景：从轻声开市逐渐走到繁盛早市，今昔环境声随翻墙交叠，走近豆皮和面窝摊听见对应制作声，昔日自行车经过时才响起经过声。静音、返回封面或隐藏页面会暂停输出。
- 食篮、店铺目录、介绍卡和资料手册平滑展开与收起，故事换页交叠淡入淡出；支持系统减少动态效果偏好。
- 看见喜欢的早餐可以收进食篮，刷新保留，还可下载自己的过早记录。
- 到店后点击“和老板聊聊”，从两三个口语化问题中选择，听摊主讲食物做法、街坊生活与武汉过早。昔今切换会改变相关回答和人物配音；随时可结束交流，回到原店铺位置。已聊话题有轻微标记并保存在本机。
- 对话中的“查看资料来源”沿用原资料手册；人物配音可重听，切换回答或离店会停止上一段，不替代环境声。
- 手机首页先显示封面，点击开始后再准备街景，并显示加载进度；准备失败可以重试。返回封面后再次进入会保留已加载的场景。

## 本版内容

六家完整早餐铺：林记热干面、豆皮铺、面窝摊、何记糊汤粉、桂姨烧梅铺和巷尾汤包馆。原来的三处街坊占位已替换为独立厨房，新增汤锅与米粉油条、开口烧梅、收口汤包、竹笼和备料台，每家有两代纸绘店主、菜单、器物小札与今昔变化。六味都可到店后收进食篮；开门时间继续随五分钟的清晨推进。

18 位行人使用每个时代 8 种不同人物：原有角色加上买菜婆婆、提饭工人、背包学生、眼镜青年、端早饭的邻居和拄杖街坊，分别有今昔装束、身高、发型和道具。黎明四位行人各不相同，后续按原来的清晨节奏加入街道。保留统一眼高的自由移动、三个生活角落、纸景翻墙、晨光、热气、食篮与具有裂缝、苔痕、磨损和修补的石板路。

新三家补绘了六张今昔墙面，细化木窗、砖缝、旧墙皮、水渍与厨房挂件，沿用原三家纸绘风格。修订过程与截图见 [墙面细化记录](WALL-DETAIL-UPDATE.md)。

六家店均有文化交流与今昔人物配音，热干面包含八个问题。现有配音共 93 段；080 / 089 两段“轧面、掸面”的读音仍保留人工复核标记，详见 [配音说明](VOICE-GUIDE.md)。

83 项自动测试与生产构建通过，桌面和触摸浏览器验证了人物配音、切换停音、来源、食篮与刷新。弱网模拟中手机图片传输量减少 85.7%，首页约 1.9 秒可点击；完整入街仍需等待素材准备。详情见 [手机加载调整](MOBILE-LOADING-UPDATE.md)。实体手机帧率与多指手势尚未实测。上方两张图片为此前 v9 的参考图。

## 本地运行

需要 Node.js 22.18 或更新版本。

```sh
npm ci
npm test
npm run build
npm run preview
```

打开终端中的地址即可。源码不包含 node_modules；GitHub Pages 的 gh-pages 分支是可直接部署的构建文件。若下载完整预览包，双击 Start-Tour.cmd 即可启动包内 dist，不需要安装依赖。不要直接双击 dist/index.html。

如果 4173 已被其他项目占用，可以运行 `npm run preview -- --port 5191 --strictPort`，访问终端显示的地址。

默认 `/` 即本版。历史原故事位于 `?sample=classic`，林记样板位于 `?sample=noodle&art=storybook`，开发观察入口位于 `?sample=street`。
